## 1. 核心术语

| 英文 | 全称（如适用） | 中文 |
|---|---|---|
| Task scheduling | — | 任务调度 |
| Path planning | — | 路径规划 |
| Conflict avoidance | — | 冲突规避 |

Task scheduling decides who does what and when; path planning determines how movement reaches a destination.

任务调度决定谁在何时做什么；路径规划决定移动对象如何到达目标位置。

## 2. 概念与使用场景

调度考虑优先级、设备能力、电量与任务时限；路径规划考虑路网、障碍和通行限制。多机器人场景中两者相互影响，最短路径可能拥堵，最近机器人也可能因低电量不适合接单。实际系统需要协调分配、路线和交通控制。

| 对比维度 | Task scheduling | Path planning |
|---|---|---|
| 问题 | 谁何时做什么 | 如何到达目标 |
| 主要约束 | 优先级、资源、电量、时限 | 路网、障碍、通行条件 |
| 相互影响 | 分配会改变交通需求 | 路径耗时影响任务分配 |

## 3. 一个工作案例

**教学示例**

两台机器人同时前往狭窄通道，单独计算都得到同一最短路线。系统通过错开进入时间或改派任务减少冲突。问题不只是每台机器人怎么走，还包括谁先执行和何时进入。

## 4. 工作中怎么说

| 场景 | 英文表达 | 中文意思 |
|---|---|---|
| 分配 | Which robot should receive this task? | 哪台机器人应接收这个任务？ |
| 路线 | Is there an alternative path around the blocked aisle? | 有绕过堵塞通道的替代路线吗？ |
| 协调 | Stagger the tasks to avoid congestion. | 请错开任务以避免拥堵。 |

## 5. 常见混淆与使用边界

- 局部最短路径不保证系统总完成时间最短，需要考虑其他资源。
- 任务分配成功不等于可立即执行，还要检查路径、交接点和安全条件。

## 6. 要点回顾

- 调度管任务与时机，规划管移动路线。
- 联合考虑拥堵、资源和时限。
- Assign the work and coordinate the movement. 分配工作，也协调移动。
