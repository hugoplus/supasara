## 1. 核心术语

| 英文 | 全称（如适用） | 中文 |
|---|---|---|
| CCN | Cargo Control Number | 货物控制号 |
| Carrier code | — | 承运人代码 |

A cargo control number identifies a cargo report in Canada's customs reporting process.

CCN用于加拿大海关货物申报中的货物记录识别，与承运人代码及具体运输记录有关。

## 2. 概念与使用场景

CBSA说明CCN由其签发的承运人代码加上承运人或货代分配的唯一参考号组成。它不是普通包裹追踪号，也不是进口放行的证明。操作时应核对报文、货物控制文件和报关相关记录是否引用一致编号，并遵守对应运输方式的申报规则。

## 3. 一个工作案例

**教学示例**

司机带来的文件与系统中货物描述一致，但CCN最后一位不同。操作员先联系申报方核实并按流程处理错误，没有仅凭车牌相同就把两条记录当成同一票货物，更没有把有编号理解为已放行。

## 4. 工作中怎么说

| 场景 | 英文表达 | 中文意思 |
|---|---|---|
| 索取 | Please provide the cargo control number. | 请提供货物控制号。 |
| 核对 | The CCN does not match the cargo report. | 这个CCN与货物申报记录不一致。 |
| 确认状态 | Has customs release been confirmed separately? | 是否已另行确认海关放行？ |

## 5. 常见混淆与使用边界

- CCN、运输工具参考号和商业发票号识别的对象不同，不应相互替代。
- 编号格式和复用限制应按当前CBSA规则及业务场景核查。

## 6. 要点回顾

- 识别号与放行状态分别核对。
- 保持相关文件和报文引用一致。
- A number identifies; it does not authorize release. 编号用于识别，不代表获准放行。
