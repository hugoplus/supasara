## 1. 核心术语

| 英文 | 全称（如适用） | 中文 |
|---|---|---|
| Cycle count | — | 循环盘点 |
| Physical inventory count | — | 实物盘点／全面盘点 |

Cycle counting checks selected inventory regularly, while a full physical count covers the defined inventory population.

循环盘点按计划持续检查部分库存；全面实物盘点在规定范围和时点覆盖全部应盘库存。

## 2. 概念与使用场景

两者都通过实物核对记录，区别主要在覆盖方式和组织安排。循环盘点可按价值、风险或库位安排频次；全面盘点通常需要更集中地控制库存移动。Physical inventory有时泛指实物库存，讨论盘点活动时加上count更清楚。

| 对比维度 | Cycle count | Full physical count |
|---|---|---|
| 覆盖 | 分批持续覆盖选定库存 | 在规定范围内集中覆盖全部库存 |
| 安排 | 按风险和频次计划 | 按统一盘点时点组织 |
| 共同要求 | 控制移动并调查差异 | 控制移动并调查差异 |

## 3. 一个工作案例

**教学示例**

仓库有2,000个SKU，每周循环盘点100个高风险库位；年末再按统一截止时间进行全面盘点。盘点中发现已发货未过账的货物，团队先核查时间差，而非立即认定丢货或调整账面。

## 4. 工作中怎么说

| 场景 | 英文表达 | 中文意思 |
|---|---|---|
| 安排 | These locations are scheduled for cycle counting. | 这些库位已安排循环盘点。 |
| 控制移动 | Please pause movements in the count zone. | 请暂停盘点区域内的库存移动。 |
| 复核 | We need a recount before posting the adjustment. | 过账调整前需要复盘。 |

## 5. 常见混淆与使用边界

- 循环盘点不是随意抽查；要有覆盖计划、差异调查和责任闭环。
- 全面盘点也不保证准确；移动控制、盲盘和独立复核都会影响结果。

## 6. 要点回顾

- 明确盘点范围、时点和移动控制规则。
- 差异先调查，调整后仍要解决原因。
- Count, investigate, then adjust. 先盘点、调查，再调整。
