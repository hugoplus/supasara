## 1. 核心术语

| 英文 | 全称（如适用） | 中文 |
|---|---|---|
| Lead time | — | 提前期／交付周期 |
| Cycle time | — | 周期时间 |
| Processing time | — | 处理时间 |

Lead time and cycle time measure elapsed time between defined events, with meanings that vary by process.

Lead time和cycle time都描述过程时间，但起止事件随业务和方法体系而变化。

## 2. 概念与使用场景

客户订单提前期常从下单到交付，工序周期可能从工序开始到完成；生产语境的cycle time也可能指连续产出之间的间隔。不要机械认为lead time总包含等待而cycle time绝不包含等待。比较报表前，应写明事件、日历规则和是否包含暂停时间。

| 对比维度 | Lead time | Cycle time |
|---|---|---|
| 常见应用 | 订单或供应提前期 | 工序周期或产出间隔 |
| 起止事件 | 按业务流程定义 | 按工序或方法体系定义 |
| 比较前提 | 明确日历和等待范围 | 明确日历和等待范围 |

## 3. 一个工作案例

**教学示例**

客户周一下单、周五收到货，订单lead time为四个自然日。仓库周三9点开始拣货、11点完成，该次拣货过程耗时两小时。两项数据描述不同边界，不能直接相减后把差值全部归为仓库浪费。

## 4. 工作中怎么说

| 场景 | 英文表达 | 中文意思 |
|---|---|---|
| 定义 | What events start and stop this clock? | 什么事件开始和结束计时？ |
| 口径 | Does this measure include queue time? | 这个指标包含排队时间吗？ |
| 比较 | We need the same time boundaries for both sites. | 两个站点需要采用相同时间边界。 |

## 5. 常见混淆与使用边界

- 自然日、工作日和工作时长不是相同单位，跨班次尤其要说明。
- 平均时间可能隐藏长尾延误，必要时同时观察分位数和异常记录。

## 6. 要点回顾

- 时间指标先定义事件，再计算数值。
- 区分订单周期、工序耗时与产出节拍。
- Define the clock before comparing the time. 比较时长前先定义计时规则。
