## 1. 核心术语

| 英文 | 全称（如适用） | 中文 |
|---|---|---|
| OMS | Order Management System | 订单管理系统 |
| WMS | Warehouse Management System | 仓储管理系统 |
| WES | Warehouse Execution System | 仓储执行系统 |
| WCS | Warehouse Control System | 仓储控制系统 |

OMS, WMS, WES, and WCS coordinate different parts of order fulfillment and warehouse automation.

这四类系统分别常见于订单协调、仓储管理、执行编排和自动化设备协调控制。

## 2. 概念与使用场景

OMS处理订单与履约安排，WMS管理库存和仓内作业，WES协调任务释放及资源节奏，WCS连接自动化设备控制。实际产品功能常有重叠，也不要求所有仓库都单独部署四套系统。应以流程、数据责任和控制时效绘制架构。

## 3. 一个工作案例

**教学示例**

客户订单由OMS分配到东仓，WMS决定拣哪些库存，WES根据工作站负载安排任务，WCS协调输送线将容器送到目标位置。设备故障后，各层需要回传状态，避免上层持续释放无法执行的任务。

## 4. 工作中怎么说

| 场景 | 英文表达 | 中文意思 |
|---|---|---|
| 定位 | Which layer decides the fulfillment location? | 哪一层决定履约地点？ |
| 协调 | Who controls task release to the automated area? | 谁控制向自动化区域释放任务？ |
| 故障 | How is equipment downtime reported upstream? | 设备停机如何向上层报告？ |

## 5. 常见混淆与使用边界

- 层级图只是解释职责的工具，实际部署可以合并或重新分配功能。
- WCS并不取代设备本地控制器和安全回路，两者责任不同。

## 6. 要点回顾

- 按决策内容区分系统职责。
- 为状态反馈和异常恢复设计完整链路。
- Trace the order down to the action. 从订单追踪到具体动作。
